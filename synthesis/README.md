# Synthesis｜跨案例综合

这个目录用于回答：

   把就业、住房、金融、commodity、AI、life-course 14 个案例放在同一张机制表中。

2. [Candidate Regularities](02_candidate_regularities.md)  
   暂定六条最值得继续接受反证的跨领域 regularities。

3. [False Friends](03_false_friends.md)  
   记录最容易被过度类比的地方，防止 framework 变成“什么都能解释”。

这一步的研究原则：

```text
先比较
→ 再压缩
→ 再找反例
→ 最后才允许升级成 general principle
```
