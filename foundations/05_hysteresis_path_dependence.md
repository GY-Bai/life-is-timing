# Foundation 05｜Hysteresis 与 Path Dependence：为什么 shock 结束以后，系统也不一定回到原轨道

> 研究状态：**A（成熟宏观 / labor / path-dependence tradition）+ B（跨领域整合）**

Life Is Timing 中的：

- recession scarring；
- Entry Gate Hysteresis；
- household deleveraging；
- human-capital pipeline；

都涉及同一个更一般的问题：

> **为什么 temporary shock 可以留下 persistent state change？**

这就是：

# Hysteresis / Path Dependence

---

## 1. “恢复到原水平”与“回到原路径”不是一回事

假设 crisis 前趋势：

```text
100
105
110
115
120
```

shock 后：

```text
100
90
95
100
105
```

虽然 level 回到了 100：

```text
Recovered in Level
```

但原趋势本来应在：

```text
120
```

所以：

```text
Trend Recovery
```

并没有发生。

这就是为什么 repo 的 recovery analysis 必须区分：

- level；
- growth；
- trend；
- distribution。

---

## 2. Labor-market hysteresis

一个 temporary recession 可能通过：

```text
unemployment
→ skill depreciation
→ employer stigma
→ lower search intensity
→ weaker matching
```

留下更持久的 unemployment / wage effect。

经典 hysteresis literature 就是从这个问题出发。

---

## 3. First-job scar 是 micro hysteresis

就业冰河期里：

```text
Temporary Hiring Freeze
```

可能通过：

```text
First Job
→ OJT
→ Employer Signal
→ Future Match
```

改变后续状态。

所以：

```text
Macro Shock
```

被写进：

```text
Micro State
```

这就是 path dependence。

---

## 4. Household balance-sheet hysteresis

房价后来反弹，并不代表：

```text
foreclosed household
```

自动回到原位置。

如果 crisis 中发生：

- forced sale；
- credit damage；
- job loss；
- relocation；
- depleted savings；

那么：

```text
state transition
```

已经发生。

后续价格恢复只能作用于：

```text
still holding the asset
```

的人。

---

## 5. Path Dependence 不等于不可逆

这是本仓库必须永久保留的边界：

```text
Path Dependence
≠ Path Determinism
```

新事件可以成为：

```text
Turning Point
```

例如：

- employer switch；
- migration；
- education；
- policy support；
- technological change；
- family formation；
- new sector demand。

所以我们更关心：

```text
Re-entry Capacity
```

而不是“命运已定”。

---

## 6. Hysteresis 与 R3

Canonical R3：

```text
Persistent Scar
≈
Entry Shock Severity
× State Dependence
× Re-entry Friction
÷ Alternative Routes
```

其中：

```text
State Dependence
```

就是 hysteresis 的核心。

过去状态会影响：

```text
future transition probability
```

---

## 7. Hysteresis 与 R2

如果 shock 改变了 slow stock：

```text
human capital
housing equity
organizational knowledge
capacity
```

那么恢复就需要：

```text
重新积累 stock
```

这使 path dependence 更持久。

所以：

```text
R2 Binding Stock
+
R3 Entry–Re-entry
```

其实是 hysteresis 的两个不同来源：

- stock rebuilding；
- state-dependent transition。

---

## 8. 核心研究问题

以后看到一个长期 scar，要问：

```text
Persistence 来自哪里？
```

可能是：

### A. Stock Damage

```text
资本 / 技能 / equity 真没了
```

### B. State Dependence

```text
过去状态改变未来 transition probability
```

### C. Belief Change

```text
experience effects 改变 risk / expectation
```

### D. Institutional Lock-in

```text
credential / contract / regulation / geography
```

四种机制不能混在一起。

---

## 9. 为什么这对年轻人重要

年轻人的风险不是：

```text
短期收入下降本身
```

而是：

```text
短期 shock 是否改变了之后十年的 transition probabilities
```

所以真正应该保护的是：

- learning；
- signal；
- mobility；
- liquidity；
- re-entry。
