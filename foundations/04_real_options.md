# Foundation 04｜Real Options：为什么“等待”有时本身就是资产

> 研究状态：**A（成熟投资理论）+ B（向人生决策的谨慎延伸）**

Life Is Timing 的 Historical / Exercisable Optionality，最接近的成熟经济学母体之一是：

# Real Options

核心思想不是：

```text
永远等待
```

而是：

> **当决策不可逆、未来不确定、且可以延迟时，等待本身具有 option value。**

---

## 1. 三个条件

Real options 最经典的条件是：

```text
Uncertainty
+
Irreversibility
+
Timing Flexibility
```

如果一个投资：

- 今天做了很难撤销；
- 明天会得到新信息；
- 不做今天并不会永久失去机会；

那么：

```text
Wait
```

不是“什么都不做”。

而是持有：

```text
Option to Invest Later
```

---

## 2. 为什么 NPV rule 可能过早触发

传统静态 NPV：

```text
Invest if NPV > 0
```

但 real-options logic 会问：

```text
如果等一段时间，
可以减少 uncertainty，
而 opportunity 不会消失，
为什么现在就不可逆地 commit？
```

所以 threshold 往往高于：

```text
NPV = 0
```

---

## 3. 与 Life Is Timing 的连接

人生中的很多决策具备：

```text
Irreversibility
+
Uncertainty
```

例如：

- 高杠杆住房；
- 高额教育债务；
- 极度 specialized training；
- 地理锁定；
- all-in entrepreneurship。

但必须谨慎：

> 这只是理论类比，不代表 Dixit–Pindyck 直接证明了“年轻人应该如何买房或选职业”。

我们真正借用的是：

```text
Option Value of Waiting
```

这个机制。

---

## 4. 为什么“等待”也有成本

Real options 不是拖延理论。

等待会损失：

- current cash flow；
- experience；
- compounding；
- scarce opportunity；
- network；
- first-mover advantage。

因此：

```text
Wait
```

只有在：

```text
Information Value
+
Avoided Irreversibility Cost
>
Foregone Opportunity
```

时才有价值。

---

## 5. 从 Historical Optionality 到 Exercisable Optionality

本仓库 V2 已经把：

```text
Optionality
```

改成：

```text
Exercisable Optionality
```

这和 real-options 逻辑更接近。

因为 option 有价值，需要：

```text
option exists
+
option can be exercised
+
exercise cost is acceptable
```

---

## 6. 对职业的谨慎延伸

职业 choice 可以拥有：

```text
embedded options
```

例如一份工作可能：

- 工资略低；
- 但技能更 transferable；
- network 更广；
- 更容易换 city / sector；
- 更容易获得下一份工作。

这不意味着一定更好。

而是它拥有更大的：

```text
future state space
```

这就是 Career as Asset 的 option-value 部分。

---

## 7. 对住房的谨慎延伸

住房具有：

- 高交易成本；
- leverage；
- location lock-in；
- 长 duration。

因此：

```text
Renting
```

有时可以被理解为：

```text
buying time / preserving mobility
```

但 renting 也有：

- rent inflation；
- no housing equity；
- tenure insecurity。

所以 real-options framework 不会自动给出：

```text
Rent > Buy
```

它只强迫我们问：

```text
不可逆性有多高？
未来信息价值有多大？
等待会损失什么？
```

---

## 8. 与 R5 的关系

Canonical R5：

```text
Effective Optionality
=
Option Set
× Exercisability
× Value Preservation
- Exercise Cost
- Carrying Cost
```

Real Options 为：

```text
Option Set
+
Wait Value
+
Exercise Threshold
```

提供成熟理论基础。

而：

```text
Value Preservation / Career / Family Constraints
```

是本仓库向 household / life-course 扩展时加入的部分。

---

## 9. 核心边界

Real options 不能被误读为：

```text
“不确定时永远不要行动”
```

如果：

- opportunity 会消失；
- learning-by-doing 很重要；
- delay 本身不可逆；
- first-mover advantage 很大；

那么：

```text
Act Early
```

本身也可能拥有 option value。
