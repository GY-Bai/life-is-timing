# Foundations｜理论母体索引

这些文档不是本仓库“原创理论”的证明，而是我们反复讨论后发现最接近的成熟学术传统。

| Foundation | 核心问题 |
|---|---|
| [Life Course Theory](01_life_course_theory.md) | 为什么同一个历史事件，发生在人生不同阶段会留下不同长期后果？ |
| [Experience Effects](02_experience_effects.md) | 为什么人会把自己亲历的一条 sample path 写进 beliefs？ |
| [Age–Period–Cohort](03_age_period_cohort_identification.md) | 为什么 Age、Period、Cohort 不能被天真地拆成三个独立 effect？ |

三者共同构成：

```text
Historical Event
× Age at Exposure
× Personal Experience
× Identification Discipline
```

也就是 Life Is Timing 的最底层方法论。

## 使用方式

本仓库以后不再把：

```text
“某代人看起来不同”
```

自动写成：

```text
“cohort effect”
```

而是优先问：

```text
Age?
Period?
Exposure?
Selection?
Persistence?
Mechanism?
```

并把所有跨领域推论继续放到 [Research Status](../RESEARCH_STATUS.md) 与 [Evidence Ledger](../evidence/EVIDENCE_LEDGER.md) 中分层管理。
