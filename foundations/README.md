# Foundations｜理论母体索引

这些文档不是本仓库“原创理论”的证明，而是与当前框架最接近的成熟学术传统。

| Foundation | 核心问题 |
|---|---|
| [Life Course Theory](01_life_course_theory.md) | 为什么同一个历史事件，发生在人生不同阶段会留下不同长期后果？ |
| [Experience Effects](02_experience_effects.md) | 为什么人会把自己亲历的一条 sample path 写进 beliefs？ |
| [Age–Period–Cohort](03_age_period_cohort_identification.md) | 为什么 Age、Period、Cohort 不能被天真地拆成三个独立 effect？ |
| [Real Options](04_real_options.md) | 为什么在不确定且不可逆的决策中，等待有时本身具有 option value？ |
| [Hysteresis / Path Dependence](05_hysteresis_path_dependence.md) | 为什么 temporary shock 结束以后，系统仍可能留在另一条路径？ |

它们共同构成：

```text
Historical Event
× Age at Exposure
× Personal Experience
× Irreversibility
× State Dependence
× Identification Discipline
```

## 使用方式

本仓库以后不再把：

```text
“某代人看起来不同”
```

自动写成：

```text
“cohort effect”
```

也不把：

```text
“等待”
```

自动写成：

```text
“更理性”
```

更不会把：

```text
“存在 path dependence”
```

写成：

```text
“命运已经决定”
```

优先问：

```text
Age?
Period?
Exposure?
Selection?
Irreversibility?
Re-entry?
Persistence?
Mechanism?
```
