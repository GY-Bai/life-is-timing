# Foundation 02｜Experience Effects：为什么人会把自己的 sample path 当成世界规律

> 研究状态：**A（成熟 behavioral-finance / expectations 文献）+ B（Matrix 比喻整合）**

Life Is Timing 的另一个核心问题是：

> **为什么人明明生活在周期里，却经常意识不到周期？**

一个重要答案是：

# Experience Effects

人形成世界观时，并不是平等使用全部历史数据。

而会对：

```text
自己亲身经历过的历史
```

赋予更高权重。

---

## 1. Depression Babies：亲历的市场回报会改变风险承担

Malmendier 与 Nagel 研究不同出生 cohort 的 lifetime macro-financial experiences。

他们发现：

```text
过去一生经历较低 stock returns 的人
→ 更少参与 stock market
→ 风险资产配置更低
```

类似地，经历过低 bond returns 的人，也更少持有 bonds。

所以：

```text
Personal Return History
→ Risk Taking
```

并不是纯理论想象。

---

## 2. Inflation：人也会用“自己的一生”估计未来

Malmendier 与 Nagel 后续研究 inflation expectations。

核心结果：

```text
Lifetime Experienced Inflation
→ Current Inflation Expectations
```

而且较新的经历通常权重更高。

所以一个出生在长期低通胀时代的人，和一个经历过高通胀时代的人，即使今天看到同一组 macro data，也可能拥有不同 prior。

---

## 3. Housing：local experience 会被外推成 national belief

Kuchler 与 Zafar 的研究尤其接近我们关于房地产的讨论。

他们发现：

```text
最近本地房价涨得更多
→ 对未来全美国房价预期更乐观
```

如果个人经历的 local housing volatility 更高：

```text
对未来 national house-price distribution
也会给出更宽的不确定区间
```

更直接的是：

```text
个人亲历 unemployment
→ 对全国未来 unemployment 更悲观
```

而且这种 extrapolation：

```text
并不取决于个人经验是否真的对 aggregate outcome 更有信息价值
```

---

## 4. 这就是 Matrix 问题的学术版本

我们在 README 里写：

```text
个人经验只是历史分布中的一条 sample path
```

Experience Effects 文献说明：

```text
人确实容易把这条 sample path
过度写进自己的 beliefs
```

所以：

```text
“I experienced X”
```

很容易被压缩成：

```text
“World works like X”
```

---

## 5. 为什么上一代经验容易失效

假设某一代人完整经历：

```text
housing appreciation
+
income growth
+
credit expansion
+
falling rates
```

他们可能形成：

```text
Buy House Early
= Universal Good Strategy
```

但真正经验其实是：

```text
Buy House
|
Housing Appreciation Regime
+
Income Growth
+
Credit Expansion
```

在传给下一代时：

```text
conditional variables
```

往往被删除。

只剩：

```text
action rule
```

这就是：

# Sample-path Compression

---

## 6. 反过来也一样危险

Experience Effects 不只制造过度乐观。

一个在严重 recession 中成年的人也可能：

- 永久低估 equity premium；
- 过度持有 cash；
- 对 employment risk 赋予过高 prior；
- 错过之后几十年的不同 regime。

所以：

```text
被周期拷打过
```

不自动等于：

```text
真正理解周期
```

也可能只是形成另一种：

```text
Experience Bias
```

---

## 7. Sophistication 能不能解决？

Kuchler 与 Zafar 发现：

```text
experience extrapolation
在 less sophisticated respondents 中更明显
```

但这不意味着：

```text
知识水平高的人可以完全摆脱 experience effects
```

更重要的是建立：

```text
Historical Base Rate
```

主动把：

```text
自己的 20–40 年样本
```

放进：

```text
更长历史分布
```

里。

---

## 8. 这不等于“反着父母做”

如果父母的 sample path 有 bias：

```text
反向执行
```

并不会自动变正确。

正确方法是恢复被删除的条件：

```text
Action
→ Action | Regime
```

然后重新判断：

```text
Current Regime
是否仍满足那些条件？
```

---

## 9. 与 Bayesian 思维的关系

Experience Effects 可以理解成：

```text
人对亲历数据给予过高 likelihood weight
```

而对：

```text
historical base rate
```

权重不足。

所以理想状态不是：

```text
Ignore Experience
```

而是：

```text
Personal Experience
+
Historical Distribution
+
Current Regime Evidence
```

共同更新 belief。

---

## 10. 核心结论

> **普通人看不到 Matrix 全貌，并不只是因为信息少；还因为人脑会把自己亲历的一小段历史赋予过高权重。**

因此真正的周期意识不是：

```text
预测明天
```

而是：

```text
知道自己的过去不是整个状态空间
```
