# Cases｜案例研究索引

这些案例不是用来“证明一个万能理论”，而是用同一套五层框架比较不同历史环境：

```text
Shock
→ Adjustment Margin
→ Stock
→ Life Stage
→ Optionality
```

| Case | 核心问题 | 证据状态 |
|---|---|---|
| [日本就业冰河期](01_japan_employment_ice_age.md) | front-loaded hiring 如何把 recession shock 放大成 entry-gate hysteresis？ | A + B |
| [美国 Recession Entrants](02_us_recession_entrants.md) | bad entry 如何通过 employer match、wage path 与 re-matching 留下 scar？ | A |
| [中国住房 Cohort：1970 vs 1993](03_china_housing_cohorts.md) | 同样 25–28 岁买房，为何在不同 regime 中不是同一笔交易？ | B + C |
| [《人生七年》Nick Hitchon](04_up_series_nick_hitchon.md) | individual alpha 如何与 education / sector / mobility beta 叠加？ | B |

## A / B / C 含义

- **A**：已有成熟文献或直接实证；
- **B**：本仓库跨文献 synthesis；
- **C**：待验证 hypothesis / research question。
