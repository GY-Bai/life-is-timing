# Cases｜案例研究索引

这些案例不是用来“证明一个万能理论”，而是用同一套五层框架比较不同历史环境：

```text

→ Adjustment Margin
→ Stock
→ Life Stage
→ Optionality
```

- **A**：已有成熟文献或直接实证；
- **B**：本仓库跨文献 synthesis；
- **C**：待验证 hypothesis / research question。
