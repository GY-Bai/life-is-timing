# Case 02｜美国 Recession Entrants：坏年份毕业，为什么会留下工资与职业轨迹 scar

> 研究状态：**A（成熟实证）**

美国案例的重要性在于：它证明就业冰河期不是日本独有现象；但美国更强的 employer switching 与 geographic mobility，又提供了一个不同的 recovery path。

## 1. 核心问题

```text
同样学历
同样年龄
只因为毕业时 unemployment rate 不同
→ 长期结果会不会不同？
```

大量研究的答案是：

```text
会
```

但影响强度、持续时间和恢复机制存在异质性。

---

## 2. Lisa Kahn：坏经济毕业，工资影响可持续很久

Kahn（2010）研究 NLSY79 中 **1979–1989 年大学毕业的白人男性**，跟踪职业生涯前二十年。

她发现：

- 在更差经济环境毕业，会带来显著负面工资影响；
- 影响在研究观察期内持续存在；
- bad-economy graduates 更容易进入较低层级 occupation；
- labor supply 本身没有明显下降。

所以不是简单：

```text
找不到工作
```

而更像：

```text
找到更差 match
→ occupation / wage path 发生偏移
```

---

## 3. Schwandt & von Wachter：Unlucky Cohorts

Schwandt 与 von Wachter 使用美国 **1976–2015 年** labor-market entrants 的大型横截面数据，发现：

```text
更高 entry unemployment
→ persistent earnings / wage losses
```

而且：

```text
less advantaged entrants
```

受影响更明显。

这说明 recession scarring 并不是一个“平均年轻人”故事。

它具有：

```text
Distributional Heterogeneity
```

即：

- 学历；
- race；
- gender；
- 初始 employer；
- 地区；
- mobility；

都会改变 scar 的深度。

---

## 4. 为什么美国和日本不同

日本更接近：

```text
Bad Entry
→ Regular Track Missed
→ Re-entry Friction High
```

美国则更容易出现：

```text
Bad Entry
→ Low-quality Employer
→ Job-to-job Switching
→ Better Employer
→ Partial Catch-up
```

所以美国案例更强调：

# Re-matching

而不是单纯的：

# First Entry

---

## 5. 加拿大研究提供了最清晰的 employer-switching 机制

Oreopoulos、von Wachter、Heisz 研究加拿大大学毕业生，发现：

- recession graduates 初始收入显著受损；
- 影响可持续多年；
- 受冲击者会通过更频繁地换 employer，逐渐进入更好的公司；
- 初始条件更好的毕业生恢复更快。

虽然这是加拿大数据，不是美国，但它对美国式灵活劳动力市场的机制解释非常重要：

```text
Recovery
≈ Search + Employer Upgrading
```

而不是：

```text
同一家公司自动把你补偿回来
```

---

## 6. Scar 不只存在于工资

Schwandt 与 von Wachter 的 life-cycle work 进一步发现：

```text
Recession Entry
```

与之后的多项 life-cycle outcome 有关系，包括：

- earnings；
- wage；
- employment；
- poverty；
- marriage / divorce；
- family size；
- disability；
- mortality。

这里必须谨慎：

这些研究主要利用更早的 recession cohorts，尤其是 1980 年代初进入市场的人，因为他们已经可以被跟踪到中年。

所以不能把完整中年效应直接当成：

```text
2008 graduates 已经被证明会得到完全相同结果
```

2008 cohort 的完整 long-run outcome 仍需要更多时间。

---

## 7. 为什么 2008 很重要

Great Recession 给出了一个典型的 timing mismatch：

```text
2008–2009
就业、招聘、housing 同时恶化
```

但之后：

```text
Financial Asset Recovery
```

明显早于：

```text
Labor-market / Wage / Household Recovery
```

对于已经有资产的 older cohort，复苏可能先表现为 wealth recovery。

对于刚毕业的年轻人，复苏更可能表现为：

```text
先经历 bad match
→ 再慢慢 re-match
```

这就是：

```text
Intergenerational Timing Sandwich
```

可能形成的地方。

### Shock


### Adjustment Margin

```text
22–25 岁 Career Formation Window
```

```text
Employer Switching
Geographic Mobility

Skill Portability

```

---

## 9. 对 Life Is Timing 的核心结论

美国研究给出的不是：

> “年轻时碰上 recession 就完了。”

而是：

```text
Bad Entry
→ Initial Scar
→ Re-matching Process
→ Heterogeneous Recovery
```

所以真正应该研究的是：

```text
谁能重新匹配？
多久能重新匹配？
重新匹配到什么质量的 employer？
```
