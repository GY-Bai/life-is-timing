# Phase II Roadmap｜从研究框架进入 Empirical Projects

> Phase II 原则：**不再以增加概念为产出，以识别机制为产出。**

优先级不是哪个故事最有趣，而是：

```text
Identification Feasibility
× Data Availability
× Ability to Falsify R1–R6
```

---

# Project 1｜Recession Scar Half-life

## 对应规律

```text
R3 Entry–Re-entry Hysteresis
```

## 核心问题

不是：

```text
recession graduates 有没有 scar？
```

而是：

> **scar 的 half-life 为什么在 Japan、US、Netherlands、Finland 不一样？**

## 核心 outcome

- earnings；
- employer quality；
- occupation；
- regular employment；
- switching；
- migration。

## 核心 explanatory variables

- entry-gate rigidity；
- employment protection；
- occupational licensing；
- employer-switching rate；
- education track；
- unemployment severity。

## Falsifier

如果：

```text
high entry rigidity
+
low re-entry
```

并不预测更长 persistence，R3 必须继续收缩。

# Project 2｜Mortgage Reset Clock

## 对应规律

```text
R4 State-Contingent Leverage Amplification
```

## 核心问题

> **同样的 policy-rate shock，为什么 household cash-flow stress 会因 mortgage reset schedule 错开几年？**

优先比较：

```text
UK fixed-term mortgage
vs
US long-term fixed mortgage
vs
more floating-rate systems
```

## 数据

- mortgage fixation structure；
- reset / refinance dates；
- payment increase；
- consumption；
- arrears；
- mobility；
- house price。

## Falsifier

如果 contract reset timing 对 household consumption / default timing 几乎没有解释力，R4 的 maturity channel 需要收缩。

# Project 3｜AI Apprenticeship Panel

## 对应规律

```text
R2 Binding Stock
+
R3 Entry–Re-entry
```

## 核心问题

> **AI 是让 junior 更快成为 senior，还是减少进入 pipeline 的 junior 数量？**

必须同时观察：

```text
Productivity per junior
× Number of juniors
× Promotion probability
× Time-to-independence
× Future experienced-worker stock
```

否则：

```text
individual augmentation
```

与：

```text
pipeline cannibalization
```

无法区分。

## 状态

长期项目。

C028 保持：

```text
PENDING
```

直到出现 longitudinal evidence。

# Project 4｜Customer Beta Validation

## 对应规律

```text
R1 Available Margin
+
R4 Balance-sheet Amplification
```

## 核心问题

> **ZIP-level household wealth / income exposure，能否预测具体 local-business revenue recovery？**

最低数据：

- anonymized POS revenue；
- ticket size；
- time-of-day；
- nearby employment；
- ZIP demographics；
- house / stock wealth proxies；
- foot traffic。

## 核心挑战

```text
ZIP demographics
≠ actual customer mix
```

因此真正需要 customer-level / transaction-level validation。

---

# Project 5｜Binding Stock Substitution Map

## 对应规律

```text
R2 Binding-Stock Principle
```

## 核心问题

> **什么情况下“慢 stock”会因为 migration、imports、technology、inventory 而不再 binding？**

候选：

- oil / gas；
- skilled trades；
- nurses / doctors；
- semiconductor capacity；
- grid equipment。

最终想估计的不是：

```text
stock rebuild time
```

而是：

```text
effective bottleneck duration
=
physical rebuild time
× bindingness
× non-substitutability
```

---

# Phase II 规则

任何 empirical project 都必须：

1. 先写 falsifier；
2. 再选数据；
3. 再决定 estimator；
4. 结果与预期相反也必须保留；
5. 不因为结果“不支持 Life Is Timing”而降级或删除。

Phase II 的成功标准不是：

```text
R1–R6 全部被证明
```

而是：

```text
我们开始知道
哪些是真的
哪些只在特定条件下是真的
哪些应该被删掉
```
