# Methods｜研究方法

这个目录用于约束整个 repo 的研究方法，而不是增加新的宏大叙事。

当前规范：

- [Identification Guide](IDENTIFICATION_GUIDE.md)：如何区分 observation、association、causal evidence、synthesis 与 hypothesis。

后续每个成熟 case 都应该能够回答：

```text
What happened?
What is identified?
What is inferred?
What is the counterexample?
What would falsify this?
```

如果答不出最后一个问题，就不应该把机制写成定论。
