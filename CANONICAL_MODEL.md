# CANONICAL_MODEL｜Life Is Timing V2

> 状态：**Canonical / Frozen for Phase I**  
> 本文件定义第一阶段结束前的唯一推荐表述。旧版本保留用于记录思想演化，但 README、synthesis、case study 与后续引用应以本文件为准。

# 核心问题

Life Is Timing 不研究：

```text
如何精准预测顶部和底部
```

而研究：

> **当历史环境发生变化时，什么变量先调整、什么存量最难修复、谁恰好在关键人生窗口暴露，以及 shock 之后还剩多少可执行选择权。**

---

# Canonical Decomposition

```text
Shock
  ↓
Available Adjustment Margin
  ↓
Binding Non-substitutable Stock
  ↓
Timing / Life-stage Exposure
  ↓
State-Contingent Amplification
  ↓
Exercisable Optionality
  ↓
Long-run Path
```

这是一个：

```text
Research Decomposition
```

不是可直接估计的结构方程。

---

# R1｜Available-Margin Principle

> **Shock 优先进入当时实际调整成本最低、制度上可执行的 margin。**

不是：

```text
Price always moves first
```

而是：

```text
Shock
→ Lowest-cost AVAILABLE adjustment margin
```

“Available” 取决于：

- liquidity；
- contract；
- regulation；
- social norm；
- search friction；
- behavioral rigidity。

典型例子：

```text
银行 → funding
企业 → hiring
家庭 → discretionary spending
商品 → price / inventory
开放经济 → FX / rate
```

但 housing price、wage 等变量可能因为 sticky contract / loss aversion 被“粘住”，于是系统改走 volume、employment 等其他 margin。

---

# R2｜Binding-Stock Principle

> **长期 persistence 由最慢、真正 binding、且不能被快速替代的关键 stock 决定。**

形式：

```text
Persistence
≈
Rebuild Time of Binding Non-substitutable Stock
```

典型 stock：

- experienced human capital；
- housing equity / debt position；
- physical capacity；
- bank capital；
- organizational knowledge；
- local demand base。

必须同时检查：

```text
imports
migration
technology
substitution
idle capacity
policy recapitalization
```

是否可以绕过原 stock。

---

# R3｜Entry–Re-entry Hysteresis

> **Bad entry 只有在 state dependence 强、re-entry friction 高、alternative routes 少时，才容易固化成长期 scar。**

形式：

```text
Persistent Scar
≈
Entry Shock Severity
× State Dependence
× Re-entry Friction
÷ Alternative Adjustment Routes
```

Alternative Routes 包括：

- employer switching；
- sector switching；
- further education；
- migration；
- lower-cost location；
- family risk sharing。

所以：

```text
Path Dependence
≠ Path Determinism
```

---

# R4｜State-Contingent Leverage Amplification

> **Leverage 不是单一放大倍数；它通过合同结构决定 shock 最终变成 default、cash-flow stress、margin call、refinancing risk 还是 lock-in。**

形式：

```text
Amplification
=
f(
LTV,
Debt Service,
Maturity,
Rate Fixation,
Recourse,
Marginability,
Refinancing Need,
Liquidity
)
```

因此同样的：

```text
Asset Price -20%
```

对：

- margin account；
- 30-year fixed mortgage；
- short-term wholesale-funded bank；

是三个不同事件。

---

# R5｜Exercisable Optionality

> **真正缓冲 scar 的不是理论上拥有多少选择，而是 shock 后仍可执行、且不会摧毁过多已有价值的选择。**

形式：

```text
Effective Optionality
=
Option Set
× Exercisability
× Value Preservation
- Exercise Cost
- Carrying Cost
```

常见 option：

- cash / waiting；
- employer switching；
- geographic mobility；
- refinancing；
- substitution；
- family transfer；
- stable long-term funding。

所以：

```text
Nominal Option
≠ Effective Option
```

---

# R6｜Locally Adaptive, Globally Incomplete Experience

> **Experience-based learning 可能是面对 structural change 的合理适应，但个人 sample path 仍不等于完整历史分布。**

因此不能写：

```text
Experience = Bias
```

更准确：

```text
Experience
can be informative locally

but
can be misleading when generalized globally
```

推荐 belief update：

```text
Personal Experience
+
Historical Base Rate
+
Current Regime Evidence
```

---

# Life-course Layer

六条 regularities 之外，人生研究还必须单独保留：

```text
Age at Exposure
```

因为同一 shock：

```text
@ 22
→ first-job / human capital

@ 32
→ mortgage / family cash flow

@ 52
→ retirement wealth / reemployment
```

所以：

```text
Historical Event
× Life Stage
```

是整个项目不可删掉的一层。

---

# Belief Layer

行为结果还取决于：

```text
What model of the world did the actor carry into the decision?
```

因此：

```text
Experience Effects
```

不是旁支，而是决定：

```text
Action | Regime
```

是否被错误压缩成：

```text
Universal Action Rule
```

的机制。

# Canonical Summary

第一阶段统一使用：

```text
Long-run Path
=
f(
Shock,
Available Margin,
Binding Stock,
Age / Timing Exposure,
Leverage Structure,
Exercisable Optionality,
Beliefs,
Institutions,
Individual Choice,
Luck
)
```

这不是命运公式。

它是一个约束地图：

```text
哪里会先动？
哪里真正绑定？
谁恰好在窗口里？
什么会放大？
还有什么可以做？
过去经验是否已经过期？
```

# Freeze Rule

Phase I 结束前：

1. 不再新增第七条 regularity，除非现有六条无法容纳新的稳定机制；
2. 新案例只有在能：
   - 推翻；
   - 收缩；
   - 显著强化；
   - 或识别 R1–R6 的边界时，才进入核心 case list；
3. 新概念优先放入 notes，而不是立即升级为 framework；
4. 所有核心引用以本文件与 [Candidate Regularities V2](synthesis/06_candidate_regularities_v2.md) 为准。
