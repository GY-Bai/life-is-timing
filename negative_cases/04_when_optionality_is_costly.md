# Negative Case 04｜有选择不等于有便宜的选择：Optionality 的 exercise cost

> 目标：攻击“options 越多越好”的直觉。  
> 结论：真正重要的是 **Exercisable Optionality**，而不是 nominal option count。

## 1. 换行业是 option，但会损失 industry-specific human capital

Derek Neal 对 displaced workers 的经典研究显示：

```text
switch industry after displacement
```

的 wage cost 与：

```text
pre-displacement experience / tenure
```

显著相关。

这说明 worker 积累的 skill 并不只有：

```text
general
or
firm-specific
```

还存在：

```text
industry-specific human capital
```

因此：

```text
“我可以换行业”
```

虽然是 option，

但 exercise 可能意味着：

```text
destroy part of accumulated capital
```

### 来源

Derek Neal, **Industry-Specific Human Capital: Evidence from Displaced Workers**, *Journal of Labor Economics*, 1995.  
https://www.derekneal.economics.uchicago.edu/files/2022/01/JOLE1995.pdf

---

## 2. 更多 search time 有时提高 match quality

Nekoei & Weber 利用 Austria 的 age-based regression discontinuity 研究 UI duration。

发现：

```text
longer UI
→ longer unemployment duration
```

但同时可以：

```text
improve reemployment firm quality
attenuate wage drops
```

这支持 real-options 直觉：

```text
more runway
→ better search
```

### 来源

Nekoei & Weber, **Does Extending Unemployment Benefits Improve Job Quality?**, *AER*, 2017.  
https://www.aeaweb.org/articles?id=10.1257/aer.20150528

---

## 3. 但“更少 search pressure”也可能变差

Washington Alternative Work Search experiment 提供非常有价值的反例。

这是一个 randomized experiment，之后又与九年 administrative wage records 连接。

对 permanent job losers：

```text
eliminating work-search requirement
```

导致：

- 更长 reemployment time；
- 更低 earnings；
- first post-claim employer tenure 更短。

也就是说：

```text
More Time / Less Constraint
```

没有自动变成：

```text
Better Match
```

### 来源

U.S. Department of Labor, **The Effects of Eliminating the Work Search Requirement on Job Match Quality and Other Long-Term Employment Outcomes**, 2015.  
https://www.dol.gov/agencies/eta/research/publications/effects-eliminating-work-search-requirement-job-match-quality

---

## 4. 为什么两个 UI 结果并不矛盾

它们提醒我们：

```text
Option Value
```

依赖：

- search technology；
- incentives；
- worker type；
- labor-market conditions；
- duration dependence；
- benefit design。

所以：

```text
Cash Buffer ↑
```

不自动等于：

```text
Outcome ↑
```

如果额外 runway 没有转化成：

```text
productive search / skill building / better matching
```

option 可能被浪费。

---

## 5. R5 为什么必须叫 Exercisable Optionality

真正可用的概念是：

```text
Effective Optionality
=
Option Set
× Exercisability
× Value Preservation
- Exercise Cost
- Carrying Cost
```

例如：

### Geographic mobility

nominal option：

```text
可以搬城市
```

exercise cost：

- spouse career；
- childcare；
- visa；
- housing transaction；
- network loss。

### Sector mobility

nominal option：

```text
可以换行业
```

exercise cost：

```text
industry-specific human capital loss
```

---

## 6. Negative case 的最终意义

不是：

```text
不要保留 optionality
```

而是：

> **不要把“理论上存在选择”误认为“冲击发生时，这个选择真的便宜、可执行、且不会破坏已有资本”。**

所以年轻人需要管理的不是：

```text
number of options
```

而是：

```text
quality of exercisable options
```
