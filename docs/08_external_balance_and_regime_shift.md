# 08｜External Balance 与 Regime Shift：账永远能平，价格替你调整

国际收支的一个重要启示是：

> **会计恒等式不会告诉你风险什么时候爆发。**

例如：

```text
Current Account
+
Financial Account
≈ 0
```

账可以连续很多年成立。

真正发生变化的是：

```text
融资条件
```

## 1. “不平衡”可以维持很久

一个国家可以长期：

```text
Current Account Deficit
```

只要：

```text
资本愿意持续流入
```

因此问题不是：

```text
什么时候账不平？
```

而是：

```text
边际融资者什么时候改变价格？
```

---

## 2. Regime shift 往往通过价格完成

当资本流入意愿下降：

```text
资本流入弱
→ FX 调整
→ 利率 / risk premium 调整
→ 信用条件变化
→ 房地产 / 资产价格调整
→ 家庭与企业资产负债表受影响
```

所以：

```text
Accounting Identity
```

始终成立。

真正被重写的是：

```text
Price
Equity
Collateral
Funding Cost
```

---

## 3. 家庭资产负债表其实是同一个逻辑

家庭永远满足：

```text
Assets = Liabilities + Equity
```

房价下跌以后，等式不会坏。

真正被压缩的是：

```text
Equity
```

因此：

> **会计平衡不代表经济状态稳定。**

同样：

> **宏观资金流能继续闭合，不代表原有 regime 能无限延续。**

---

## 4. 新西兰式结构为何有代表性

一个典型旧 regime 可以是：

```text
较高利率
→ 海外资本流入
→ FX 有支撑
→ Mortgage Credit
→ Housing
→ Collateral
→ 更多信贷
```

当边际融资条件改变：

```text
Capital Inflow ↓
→ FX / Rate 先动
→ Credit 收紧
→ Housing 调整
→ Household Balance Sheet
→ Consumption
→ Employment
```

这再次符合：

```text
Fast Price
→ Credit
→ Contract
→ Labor
→ Slow Stock
```

---

## 5. 为什么这与 Life Is Timing 有关

同样一个：

```text
买房
借贷
创业
跨境配置
```

动作，在不同融资 regime 下根本不是同一笔交易。

所以：

```text
Action
```

必须写成：

```text
Action | Funding Regime
```

否则我们就会把：

```text
上一代在廉价信用下成功的策略
```

错误地迁移到：

```text
去杠杆 / 高融资成本时代
```

---

## 6. 核心命题

> **很多 regime 并不是因为“账突然不平”而结束，而是因为维持同一套账的边际价格变了。**

所以真正应该监控的不是恒等式本身，而是：

- 谁在融资；
- 谁在接盘；
- collateral 质量；
- funding cost；
- FX；
- risk premium；
- refinancing capacity。

这些变量决定同一套会计结构能维持多久。
