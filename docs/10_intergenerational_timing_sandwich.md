# 10｜Intergenerational Timing Sandwich：为什么有些 cohort 同时错过职业与资产窗口

不同出生 cohort 的命运差异，不一定来自“哪一代更努力”。

有时真正的差异是：

```text
他们在关键年龄，历史正运行到不同的 phase。
```

## 1. 三代人的典型错位

可以想象三个相邻 cohort。

### Cohort A：资本形成窗口

```text
年轻时收入增长
+ 资产估值较低
+ 信贷扩张
+ 房地产 / 股票长期上行
```

于是完成：

```text
Labor Income
→ Savings
→ Asset Ownership
→ Capital Gain
```

### Cohort B：夹层 cohort

```text
毕业时就业冰河
→ 首职质量弱
→ 工资增长慢
→ 储蓄能力弱
→ 危机后资产却先反弹
→ 等收入恢复，便宜资产窗口已经结束
```

于是同时错过：

```text
Career Entry Window
+
Asset Entry Window
```

### Cohort C：劳动稀缺窗口

如果之后人口、劳动力供给或技能供给下降：

```text
Labor Scarcity
→ Wage Bargaining Power
→ 更高 entry wage / 更快晋升
```

于是夹在中间的 cohort 可能显得格外不利。

---

## 2. 为什么这不是简单的“代际不公平”

它更接近：

```text
不同 cohort
× 不同 Life Stage
× 不同 Macro Regime
```

一个 cohort 的：

```text
22 岁
```

可能落在：

```text
招聘冻结
```

另一个 cohort 的：

```text
28 岁
```

可能落在：

```text
低估值资产窗口
```

再一个 cohort 的：

```text
22 岁
```

可能落在：

```text
劳动力短缺
```

所以“年龄一样”并不等于“机会集一样”。

---

## 3. 双重 scar

夹层 cohort 最值得研究的是：

```text
Human-capital Scar
+
Balance-sheet Scar
```

职业端：

```text
坏首职
→ 低工资
→ 弱晋升
→ 低储蓄
```

资产端：

```text
没有资本参与低价资产
→ 危机后资产反弹
→ 进入时估值已高
```

于是两个 scar 会互相强化：

```text
低收入
→ 低资产
→ 低 liquidity
→ 低 mobility
→ 更难 re-match
```

---

## 4. 为什么股市先恢复，反而可能扩大 cohort 差异

Jet Lag 的一个重要结果是：

```text
Asset Recovery
往往早于
Employment Recovery
```

这意味着：

```text
已经有资产的人
```

可能先恢复。

而：

```text
主要依赖工资、又刚进入市场的人
```

还在就业冰河。

于是同一轮“复苏”可能同时制造：

```text
Older / Asset-owning Cohort
Wealth Recovery

Young / Labor-dependent Cohort
Career Delay
```

这不是简单的资产上涨好或坏。

而是不同 cohort 对恢复顺序的暴露不同。

---

## 5. 一个可检验的框架

可以把 cohort outcome 写成：

```text
Outcome_c
=
Career Entry Regime
+
Asset Entry Regime
+
Housing Entry Regime
+
Labor Scarcity Regime
+
Policy Regime
+
Re-matching Capacity
```

未来案例可以包括：

- 日本就业冰河期；
- 美国 2008 recession graduates；
- 英国不同出生 cohort 的 housing wealth；
- 中国房地产不同购房 cohort；
- 欧洲青年就业与住房 affordability。

---

## 6. 这个概念最重要的边界

“夹层 cohort”不能写成：

```text
某一代人注定倒霉
```

因为 cohort 内部还有巨大异质性：

- 家庭资产；
- 教育；
- sector；
- geographic mobility；
- leverage；
- occupation；
- luck。

它只是提醒我们：

> **同一代人面对的共同历史背景，可以改变整个 opportunity distribution，但不会决定每一个人的终点。**
