# 00｜核心框架：Shock → Adjustment Margin → Stock → Life Stage → Optionality

这个仓库的核心不再只是“就业冰河期”或“危机后的 Jet Lag”。

过去多轮讨论逐渐收敛出一个更一般的框架：

```text
Layer 1 — Shock
宏观 / 金融 / 技术 / 地缘冲击

Layer 2 — Adjustment Margin
系统先让哪个变量动？

Layer 3 — Stock
哪些存量无法快速重建？

Layer 4 — Life-cycle Exposure
冲击发生在人生哪个窗口？

Layer 5 — Optionality
个人 / 企业 / 家庭还能不能换轨？
```

可以抽象成：

```text
Long-run Outcome
=
Shock
× Adjustment Mechanism
× Stock Constraint
× Life Stage
× Optionality
```

## 1. Shock：真正重要的不是冲击本身，而是冲击打在哪里

同一场冲击，对不同系统的含义完全不同。

例如：

```text
利率上升
```

可能首先打到：

- 高杠杆家庭；
- 长久期资产；
- 依赖外部融资的企业；
- 房地产；
- private credit；
- 尚未形成稳定现金流的年轻人。

所以“宏观冲击”不是一个统一变量。

真正需要问的是：

> 谁的资产负债表、现金流、职业路径或融资链条，对这个冲击最敏感？

---

## 2. Adjustment Margin：系统先让谁动

这是整个框架里最重要的新概念之一。

当系统受到冲击时，不是所有变量一起变化。

通常最先调整的是：

```text
最流动
最容易重定价
最容易取消
最容易推迟
最少需要长期承诺
```

的变量。

例如：

```text
金融市场：
价格先动

企业：
招聘先冻

劳动力市场：
temporary / contractor 先动

国际收支：
汇率 / 利率先动

商品供给：
价格先动

家庭：
可选消费先砍
```

因此：

```text
System Shock
→ Fastest Available Adjustment Margin
```

当这一层的调整能力耗尽，压力才会继续传导到更慢、更难动的变量。

---

## 3. Stock：真正制造长期 scar 的，是慢变量

价格可以一天变化 10%。

但以下东西不能一天重建：

- 一个 senior engineer；
- 一座铜矿；
- 一家银行的健康资产负债表；
- 一套稳定的职业网络；
- 一个家庭的首付；
- 一条完整的 apprenticeship pipeline；
- 一座城市的住房库存。

因此要区分：

```text
Flow / Price
```

和：

```text
Stock
```

很多所谓“危机后的报复性上涨”，本质上是：

```text
Fast Variable
```

在替：

```text
Slow Stock
```

承担调整。

---

## 4. Life Stage：同一个冲击，年龄不同，打到的资产不同

同一场危机：

```text
Shock @ 22
→ 第一份工作 / 人力资本

Shock @ 32
→ 房贷 / 家庭现金流 / 职业中段

Shock @ 52
→ 退休资产 / 高峰收入 / 再就业难度
```

所以：

```text
Age at Shock
```

不是背景变量，而是核心交互项。

这也是为什么出生年份重要：

```text
Birth Cohort
→ Age at Historical Event
→ Exposure
→ Long-run Path
```

---

## 5. Optionality：真正决定 scar 是否固化

路径依赖不等于路径决定论。

关键问题是：

```text
Can You Re-match?
```

Optionality 可以来自：

- 现金；
- 低固定支出；
- 可迁移技能；
- 地理 mobility；
- 行业 mobility；
- network；
- 时间；
- 较低杠杆；
- 可以延迟不可逆决策的能力。

所以：

```text
Scar Persistence
≈
Initial Damage
× Friction
× Irreversibility
÷ Optionality
```

---

## 6. 五层框架为什么能统一看似无关的问题

### 就业冰河期

```text
Shock
→ 招聘冻结
→ junior pipeline 中断
→ human-capital stock 受损
→ 22 岁 cohort 暴露
→ re-matching 决定长期结果
```

### 金融踩踏

```text
Shock
→ 可交易资产先卖
→ 价格下跌 / VaR 上升
→ funding liquidity 恶化
→ balance-sheet stock 受损
→ 有 liquidity 的主体能活下来
```

### 重资产供给短缺

```text
多年低投资
→ 旧产能硬撑
→ spare capacity 消失
→ price 先涨
→ capital stock 多年后才能补回
```

### 房地产 cohort

```text
同样 28 岁买房
× 不同估值 / 信贷 / 人口 regime
→ 完全不同的 household balance sheet
```

### Local Business

```text
宏观冲击
→ 客群资产 / 工资受损
→ 不同 customer beta
→ 同一街区不同商户恢复速度不同
```

---

## 7. 一个暂时的总命题

> **系统遭遇冲击时，最先变化的往往不是最重要的变量，而是最容易变化的变量。**

进一步：

> **长期结果由慢变量决定，而短期价格由快变量决定。**

再进一步：

> **人生 timing 的本质，是关键决策窗口恰好暴露在哪种系统状态下，以及当系统发生 regime shift 时，你是否还保有重新选择的权利。**
