# 04｜Insider–Outsider 与人力资本管线：为什么冲击会集中到“还没上车的人”

就业冰河期不能只理解为“失业率上升”。

更重要的问题是：

> 企业在压力下，究竟先削减谁？

## 1. 调整经常先发生在入口，而不是存量员工

当企业面对不确定性时，常见顺序是：

```text
冻结招聘
→ 减少 internship / graduate hiring
→ contractor / temporary 缩减
→ 停止扩张
→ 最后才是核心正式员工
```

原因并不神秘：

- 不招一个新人，比解雇一个已有员工更容易；
- incumbent 已经具备 firm-specific human capital；
- 解雇有法律、组织和士气成本；
- 新人招聘属于未来承诺，可以直接取消。

所以：

```text
Employment Protection
```

有时会形成：

```text
Insider Protection
+
Outsider Exclusion
```

---

## 2. 为什么日本式制度会放大毕业年份

如果一个系统具有：

```text
新卒集中招聘
+ 正社员轨道
+ 企业内部 OJT
+ 长期晋升
+ regular / nonregular 分割
```

那么：

```text
没赶上毕业入口
```

可能不是“晚几年进去”这么简单。

而是：

```text
没进入主轨
→ 没得到同样 OJT
→ 没得到同样 mentor / project
→ 简历标签变化
→ 后续筛选继续基于过去状态
```

这可以叫：

# Entry Gate Hysteresis

入口冲击在制度摩擦下被放大成长期差异。

---

## 3. 人力资本不是个人自己就能生产

经典叙述容易把 human capital 写成：

```text
个人学习
→ 能力提升
```

但现实更接近：

```text
个人能力
× 组织训练环境
× mentor
× 项目质量
× 反馈频率
```

很多高级能力都需要：

- 看 senior 如何判断；
- 接触真实复杂问题；
- 犯错后被纠正；
- 逐渐承担更高责任；
- 长期观察组织如何协调。

所以 junior 岗位的价值不只是工资。

它还是：

```text
未来 senior 的生产线
```

---

## 4. Human-capital Cannibalization

AI 时代出现一个新的风险。

单个企业可能发现：

```text
1 Senior + AI
```

可以完成过去：

```text
1 Senior + 3 Juniors
```

的工作。

短期最优解于是变成：

```text
少招 Junior
```

但今天的 senior 本来就是十年前的 junior。

于是可能形成：

```text
Senior + AI
→ Junior Hiring 下降
→ Apprenticeship 变薄
→ 中间层经验人才减少
→ 未来 Senior Pipeline 变窄
```

这就是：

# Human-capital Cannibalization

企业用过去积累的人力资本存量提高当前效率，却减少下一代人力资本形成。

---

## 5. 但 AI 也可能成为 learning accelerator

这不是单向悲观故事。

AI 也可能：

- 提供即时反馈；
- 帮新人解释复杂系统；
- 降低查资料成本；
- 把隐性知识的一部分显性化；
- 缩短从 novice 到 competent 的时间。

因此存在两条竞争路径：

### Automation Path

```text
AI 替代新人任务
→ Junior 数量减少
→ 学习入口减少
→ Pipeline 断裂
```

### Augmentation Path

```text
AI 辅助新人
→ 即时反馈
→ 学习速度提高
→ 新人更快接近 senior
```

真正值得研究的问题是：

> **AI 替代的是 learning task，还是放大了 learning process？**

---

## 6. 一个更完整的人力资本管线模型

```text
Junior Entry
→ Repetition
→ Feedback
→ Tacit Knowledge
→ Project Ownership
→ Mid-level
→ Senior
→ Mentor Next Cohort
```

如果任意一段被长期切断：

```text
Pipeline Flow ↓
```

若干年后就会体现为：

```text
Experienced Worker Stock ↓
```

所以：

```text
Hiring Freeze Today
```

有可能是：

```text
Skill Shortage Years Later
```

---

## 7. 研究假设

值得继续验证：

1. 高就业保护制度是否把更多波动转移到 hiring margin；
2. junior hiring decline 是否会在若干年后体现为经验人才缺口；
3. AI 采用强度高的行业，junior-to-senior pipeline 是否变薄；
4. 有系统 mentorship / apprenticeship 的组织，是否更能抵抗这种断层；
5. remote work 是否会进一步削弱 tacit knowledge transfer。

核心命题：

> **就业市场真正的慢变量不是岗位数量，而是能够独立解决复杂问题的人力资本存量。**
